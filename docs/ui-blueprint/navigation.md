\# RouteX Navigation Blueprint



\## Primary Navigation



Dashboard



Fleet



Deliveries



Transactions



Reports



Administration



Settings



\---



\## Navigation Philosophy



Navigation should be simple.



Users should never wonder where information lives.



Every major section represents a business domain.



\---



\## Sidebar



Default:



Collapsed



Displays:



\- Icons only



Expanded:



\- Icons

\- Labels



\---



\## Search



Global.



Always accessible from the header.



Searches:



\- Plate Number

\- Delivery ID

\- Driver

\- Client



Search should navigate directly to records.



There is no dedicated Search page.



\---



\## Navigation Behavior



Dashboard → Overview



Fleet → Trucks



Deliveries → Operations



Transactions → Company Expenses



Reports → Business Reporting



Administration → Users and Logs



Settings → Personal Preferences
